VDP1 FBRAM reads/writes
-----------------------
  Grandia
    Combat scenes

    The event timeline is as follows:
    ==== frame 1 ====
    1. SCU DMA 224 lines of 0x160 bytes from 0x60ECA80 (fixed) to VDP1 FBRAM, zeroing out contents
    2. SCU DMA VDP1 command table from 0x6082878 to VDP1 VRAM
    3. VDP1 drawing triggered with PTM=1. This will be copied to VDP2 NBG1 on frame 2 below
    4. SCU DMA 224 lines of 0x160 bytes from VDP1 FBRAM to 0x60ECC00 onwards, copying first rendered VDP1 frame
    5. SCU DMA 224 lines of 0x160 bytes from 0x60ECA80 (fixed) to VDP1 FBRAM, zeroing out contents
    6. SCU DMA VDP1 command table from 0x607E878 to VDP1 VRAM
    7. VDP1 drawing triggered with PTM=1. This will be used as the sprite layer by VDP2 on next swap
    ==== frame 2 ====
    8. SCU DMA 0x13400 bytes from 0x60ECC00 to 0x5E20000 (VDP2 VRAM), copying the first VDP1 frame to VDP2 NBG1
    ==== repeat ====

    VDP1 framebuffer swap occurs on frame 1, displaying the previous pair of VDP1 frames.
